# Premium Seafarer Resume Builder

Локальный конструктор премиального резюме моряка. Итоговый формат — **только автономный HTML**.
Без регистрации, без сервера, без внешних сервисов и CDN. Данные не покидают ваш компьютер.

## Файлы
- `index.html` — конструктор (форма + live preview)
- `styles.css` — стили интерфейса и резюме
- `app.js` — логика: автосохранение, импорт/экспорт JSON, генерация standalone HTML
- `INSTRUCTIONS.md` — подробная инструкция по использованию
- `DEVLOG.md` — журнал разработки по этапам
- `schema.example.json` — пример данных (синтетический placeholder)

## Запуск
1. Откройте `index.html` двойным кликом в любом современном браузере (Chrome / Edge / Firefox).
2. Заполните форму слева — превью справа обновляется автоматически.
3. Нажмите **Download resume HTML** — получите самодостаточный файл `<имя>-resume.html`.
4. Готовое резюме можно открыть где угодно и напечатать через Print → Save as PDF (по желанию пользователя; это выбор браузера, а не функция конструктора).

## Возможности
- Live preview, автосейв в localStorage, восстановление после перезагрузки.
- Add/Remove/Reorder судов; Add/Remove сертификатов; placeholder-и при пустых полях.
- Load sample data / Clear all data / Export JSON / Import JSON (устойчив к битым файлам).
- Фото: JPG/PNG/WEBP/GIF, сжатие до 900px; слишком большое фото — предупреждение без падения.
- Экранирование пользовательского ввода (защита от XSS в генерируемом HTML).
- Текст сгенерированного резюме — только на английском.

## Приватность
Приложение полностью офлайн: никаких запросов наружу, аналитики или водяных знаков.
