# Инструкция по использованию — Premium Seafarer Resume Builder

> Полная инструкция для пользователя конструктора резюме моряка.
> Краткая версия — в файле `README.md`.

---

## 1. Что это и что нужно, чтобы начать

**Premium Seafarer Resume Builder** — локальный конструктор премиального резюме моряка.
Итоговый документ создаётся **только в формате автономного HTML**: один файл, который
открывается в любом браузере, печатается и пересылается без каких-либо зависимостей.

Вам нужны только:
- компьютер (Windows / macOS / Linux);
- любой современный браузер: Chrome, Edge, Firefox, Safari;
- папка проекта с файлами `index.html`, `styles.css`, `app.js`.

**Не нужны:** интернет, регистрация, сервер, установка программ, платные сервисы.
Данные никуда не отправляются — всё работает офлайн в вашем браузере.

⚠️ Не открывайте файлы `design/*` как часть рабочего процесса — это справочная
документация по дизайну (референсы, токены, превью компонентов). Для работы
с резюме открывайте именно `index.html`.

---

## 2. Запуск

1. Найдите файл `index.html` в папке `seafarer-resume-builder`.
2. Откройте его двойным кликом (или через браузер: «Файл → Открыть файл»).
3. Интерфейс разделён на две части:
   - **слева** — форма ввода данных;
   - **справа** — живое превью резюме (Live Preview), обновляется автоматически.

Если после обновления файлов выглядит старая версия — сделайте жёсткий сброс кэша:
`Ctrl + F5` (Windows) или `Cmd + Shift + R` (macOS).

## 3. Пошаговое заполнение резюме

Блоки формы идут сверху вниз. **Обязательных полей нет** — можно заполнить
что угодно, пустые места в резюме будут аккуратно отмечены placeholder-ами
вида `[AGE]`, `[Vessel Name]`, `[DD.MM.YYYY]`. Весь текст внутри готового
резюме отображается на английском языке.

### Шаг 1. Personal / Header (шапка резюме)
- **Full Name** — имя и фамилия как в паспорте (латиницей).
- **Rank / Position** — квалификация, например `Second Engineer`, `Able Seaman`.
- **Age**, **Nationality** — возраст и гражданство.
- **Passport Number**, **Seaman Book Number** — номер паспорта и seamans book.
- **Photo (JPG/PNG)** — нажмите «Choose photo…» и выберите файл изображения.
  Фото автоматически уменьшается до разумного размера и показывается в миниатюре.
  Кнопка «Remove» убирает фото. Поддерживаются JPG / PNG / WEBP / GIF.

### Шаг 2. Personal Information
Дата рождения, рост/вес, уровень английского (выпадающий список), дата
готовности к рейсу (Available From), телефон, email, город/страна,
общий морской стаж (Total Sea Service). Формат дат в примере — `DD.MM.YYYY`.

### Шаг 3. About Me
Многострочное поле «о себе». Текст попадает в резюме **как есть**, поэтому
рекомендуется писать на английском. Стартовый шаблон подсказывает стиль:
*“Experienced marine officer with a strong safety record…”*.

### Шаг 4. Sea Service Experience (стаж по судам)
- Нажмите **«+ Add vessel»** — появится карточка судна.
- Поля карточки: **Vessel Name**, **Vessel Type**, **Rank**, **Period**,
  **Duration**, **Duties / Remarks**.
- Кнопки справа в карточке:
  - **↑ / ↓** — переместить запись выше/ниже (меняет порядок в резюме);
  - **⧉** — дублировать запись (удобно при ротациях: то же судно, новый ранг);
  - **✕** — удалить запись.
- **«Duplicate last»** под списком копирует последнюю добавленную карточку.
- Если записей нет — показывается нейтральный placeholder, ничего не ломается.

### Шаг 5. Certificates
- **«+ Add certificate»** — карточка с полями **Certificate Name** и
  **Valid Until** (например `STCW Basic Safety Training`, `2027-05`).
- Кнопки **⧉** (дублировать) и **✕** (удалить) работают так же, как у судов.

### Шаг 6. Footer
Текст внизу резюме. Если оставить пустым, подставится стандартная фраза:
*“References and original documents available upon request.”*

### Шаг 7. Block Colors (цвета резюме)
- **Пресеты палитр**: `Navy Gold` (тёмно-синий + золото, по умолчанию),
  `Black Champagne` (уголь + шампань), `Ocean Platinum` (сланец + платина).
  Нажмите кнопку пресета — вся палитра применится сразу.
- **Индивидуальные цвета**: ниже расположены 12 цветковых полей — фон шапки,
  текст шапки, акцент, заголовки секций, фон страницы, основной/вторичный
  текст, таблица (заголовок и зебра-строки), карточки сертификатов, футер.
  Меняйте любой — превью обновится мгновенно.
- **Reset** — вернуть палитру по умолчанию.
- Защита от низкого контраста: если выбранная пара цветов почти не читается,
  приложение автоматически подставит безопасный оттенок текста.

## 4. Автосохранение и восстановление

- Все изменения сохраняются **автоматически** в памяти браузера (localStorage).
  В правом верхнем углу появляется метка **«Saved ✓»**.
- После закрытия и повторного открытия `index.html` данные восстановятся.
- Данные хранятся **только в этом браузере на этом компьютере**. Очистка
  истории/данных сайта в браузере удалит их — делайте бэкап через Export JSON.
- Если фото слишком большое для автосохранения, вы увидите предупреждение;
  приложение при этом продолжит работать.

## 5. Панель инструментов (внизу формы)

| Кнопка | Что делает |
|---|---|
| **Load sample data** | Заполняет форму синтетическими примерами-плейсхолдерами — удобно для демонстрации дизайна. Замените их своими данными. |
| **Clear all data** | Полностью очищает форму и превью (спросит подтверждение, только если есть данные). |
| **Export JSON** | Скачивает файл с вашими данными — бэкап или перенос на другой ПК. |
| **Import JSON** | Загружает ранее сохранённый JSON обратно в форму. Битый файл не сломает приложение — появится сообщение об ошибке. |
| **⬇ Download resume HTML** | Главный результат: скачивает автономный файл `<имя>-resume.html`. Дублируется кнопкой в шапке страницы. |

## 6. Горячие клавиши и мелкие удобства

- **Ctrl + S** (Mac: **Cmd + S**) — скачать готовое резюме HTML (вместо сохранения страницы браузером).
- **⌨ Shortcuts** (в шапке) — открывает окно со списком горячих клавиш и советами; закрытие — `Esc`, крестик или клик мимо окна.
- **Undo** — после удаления судна или сертификата в статус-баре ~8 секунд доступна кнопка «Undo»; верните запись на исходную позицию одним кликом.
- Превью прокручивается синхронно с формой (там, где браузер это разрешает).
- **Print preview** (над превью) — печать именно резюме, без интерфейса конструктора.

## 7. Скачать и показать резюме работодателю

1. Нажмите **«⬇ Download resume HTML»**.
2. Полученный файл — единый HTML со встроенными стилями: его можно
   отправить по почте, положить на флешку, открыть на любом компьютере.
3. При необходимости распечатайте: откройте файл → `Ctrl/Cmd + P`.
   Опция «Save as PDF» в диалоге печати браузера — выбор самого пользователя,
   конструктор PDF не генерирует.
   Совет: в диалоге печати включите «Background graphics», чтобы тёмная
   шапка и золотые линии сохранились.

## 8. Частые вопросы

**Нужен ли интернет?** Нет. Всё работает полностью офлайн.

**Куда попадают мои данные?** Никуда. Они живут только в localStorage вашего
браузера и в скачанных вами файлах. Аналитики, трекеров и водяных знаков нет.

**Резюме на другом языке?** Текст шаблона резюме (подписи, заголовки секций)
англоязычный по требованию продукта. Содержимое полей — то, что вы напишете;
рекомендуется английский.

**Печатаю — а фон шапки белый?** Включите фоновую графику в настройках печати
(см. пункт 7).

**Перенёс JSON на другой компьютер — фото пропало?** Фото сохраняется в JSON
как код изображения, но очень большие фото могут быть исключены из автосохранения;
перенесите файл JSON и при необходимости добавьте фото заново.

**Хочу вернуться к прежнему виду резюме?** Block Colors → Reset, либо
пресет Navy Gold.

## 9. Быстрый старт за 3 минуты

1. Откройте `index.html`.
2. Нажмите **Load sample data** — посмотрите готовое премиальное резюме в превью.
3. Замените данные на свои (имя, ранг, суда, сертификаты), при желании
   подберите палитру в Block Colors.
4. Нажмите **⬇ Download resume HTML** — файл готов к отправке.
