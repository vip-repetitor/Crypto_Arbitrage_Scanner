# Контекст проекта BONDINVEST

Эта папка — источник контекста. **Перед каждым рабочим циклом** (любая задача по проекту)
агент обязан прочитать все файлы отсюда и использовать их содержимое как актуальный контекст.

## Порядок загрузки контекста (на каждый цикл)
1. `ls BONDINVEST/context/` — найти все файлы (игнорировать `.gitkeep`).
2. Прочитать каждый файл целиком; при конфликте — приоритет у более нового по дате изменения.
3. Сверить требования файлов с текущим состоянием `BONDINVEST/app/` и `CHECKLIST.md`.
4. Только после этого приступать к задаче пользователя.
